Import past market candles

A CSV is a simple spreadsheet-style file containing past candle prices. It lets you replay real market history instead of relying on practice data.

Your file should contain: Date/Time, Open, High, Low and Close. Volume is optional. Each row should represent one candle.
The format example only shows how columns should look; it is NOT real XAUUSD history. Use genuine historical XAUUSD data for a meaningful backtest. The importer recognises comma, semicolon and tab-separated files; common Date/Time or separate Date + Time columns; and common OHLCV heading variations. Invalid rows and duplicate timestamps are skipped and reported.
